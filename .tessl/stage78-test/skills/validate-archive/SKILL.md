# Validate the synthetic archive workflow

Run only from the root of jscraik/skills-sdk. Before installing dependencies,
require the launch instructions to supply EXPECTED_HEAD as a full commit SHA and
verify both the current HEAD and its first parent. HEAD must equal EXPECTED_HEAD.
The parent must equal b19c899a553023c2670c518f771d5826d319c067. The commit may
change only .tessl/stage78-test/ files. Stop and report any mismatch.

Use the workspace's pinned Python 3.12 and uv 0.13.5. If mise is missing,
use the checksum-verified Linux x64 mise bootstrap documented in the checkout's
.circleci/config.yml, with an install location confined to the disposable worker.
Stop if its prerequisites or checksum fail. Use the repository-root mise trust
and ceiling settings for both commands.

```bash
MISE_CEILING_PATHS="$PWD/.." MISE_TRUSTED_CONFIG_PATHS="$PWD/.mise.toml" mise exec -- uv sync --frozen
MISE_CEILING_PATHS="$PWD/.." MISE_TRUSTED_CONFIG_PATHS="$PWD/.mise.toml" mise exec -- uv run --frozen --no-sync pytest -q tests/test_plugin_build.py tests/test_package_archive_verification.py
```

Stop on failure. Report checkout and parent SHAs, Python and uv versions,
command exits, pytest counts, and the first blocker if any. The Stage 7 suite
tests the production emitter and synthetic round-trip. The Stage 8 subset
tests local archive verification with separate synthetic fixtures.

Keep all generated bytes in the disposable worker. If an archive digest was
observed, report the digest and how it was obtained. Do not modify tracked
files, export an archive, publish, install into a host, commit, push, open a PR,
or start additional runs.
